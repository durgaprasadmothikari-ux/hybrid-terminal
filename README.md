# CyberTerm — Custom Terminal Application

CyberTerm is a customizable terminal application built with JavaScript and web technologies. This project is under active development.

## Features

- Terminal application interface
- Modular JavaScript source code
- Custom styling with CSS
- Windows launcher (`cyberterm.bat`)
- Test suite for selected components

## Technology Stack

- JavaScript
- HTML
- CSS
- Node.js and npm

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/durgaprasadmothikari-ux/hybrid-terminal.git
cd hybrid-terminal
```

Install dependencies:

```bash
npm install
```

### Running the Application

Check the `scripts` section in `package.json` to find the available commands. If the project defines a `start` script, run:

```bash
npm start
```

On Windows, you can also check whether `cyberterm.bat` launches the application correctly.
